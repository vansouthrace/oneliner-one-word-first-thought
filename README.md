Entry for the [make.fun bounty](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8): one word, the first that comes to mind.

The program writes a single word to `/output/entry.txt`. The word: **labyrinth** — a maze you can get lost in, which is exactly what a first thought feels like. No topic, no explanation, no second draft.

## How it works

`main.ts` trims the word and writes it to `/output/entry.txt`, nothing else.
